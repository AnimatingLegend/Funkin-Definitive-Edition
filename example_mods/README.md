# Modding Readme

Welcome to the `mods` directory! Here is where you can upload custom assets, aswell as custom song events!

Everything in these folders are easy-to-use templates to get your foot in the door with modding in this engine.

## Documentation

For a thorough breakdown on how modding works for this engine, you should follow the **[funkin-cookbook](https://thekade.net/funkin-cookbook/)**. as it tells you more about character / stage implementation, and programming with `hscript` / `.hxc`.

> [!NOTE]
> Funkin' Definitive Edition's `.json` structure is a _tad_ bit different from the base games, so id recommend using engines structures instead.

Visit the **[`MODDING_TEMPLATE`](../docs/MODDING_TEMPLATE)** to get the data structure for characters, stages, and plenty more!
